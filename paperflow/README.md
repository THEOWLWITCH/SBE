# PaperFlow: ניהול מאמרים ומחקרים

מערכת מקומית בקובץ אחד (`PaperFlow.html`). פותחים אותה בדפדפן **Chrome** או **Edge** במחשב של דני. לא צריך התקנה ולא צריך אינטרנט.

## הפעלה ראשונה
1. פותחים את `PaperFlow.html` ומזינים את קוד הכניסה **2412**. המחשב מוגדר כ"מחשב של דני".
2. לוחצים **"שמירת קובץ נעול"**. יורד עותק שנעול למחשב הזה. שמים אותו במקום קבוע, עובדים רק איתו, ומוחקים עותקים לא נעולים.
3. רושמים את **מפתח השחזור** שמוצג על המסך. הוא נדרש רק אם נתוני הדפדפן יימחקו.
4. בעמוד **ניהול**, בוחרים **"חיבור תיקייה"**. לכל מאמר תיפתח שם תיקייה (למשל `P003 - GBM Calcite`), וכל הגרסאות יישמרו בה.
5. לוחצים **"הפעלת התראות"** כדי לקבל תזכורות במחשב.

## מה יש במערכת
- **מאמרים**: לכל מאמר מספר קבוע ומספר גרסה שעולה בכל העלאה (v1, v2…). אפשר לערוך את כל הפרטים.
- **תיעוד שלבים**: בוחרים מרשימה מה נעשה (תכנון, סבבי טיוטה לשותפים, שליחה לעיתון עם קישור ואישור קבלה, קבלת הערות עם מועד הגשה, הגשת תיקונים, אישור, פרסום, עדכון אתרים ומערכות). לכל צעד נשמרים תאריך ושעה, גם להעלאת קובץ.
- **תיקיית גרסאות**: העלאה או גרירה של קובץ. עריכה ב-Word ישירות בתיקייה ואז "סריקת שינויים", והמערכת רושמת גרסה חדשה.
- **מסמך עבודה**: עורך טקסט מובנה (עם תבנית IMRaD) ששומר גרסאות כקובץ Word.
- **שליחה במייל**: המערכת מכינה טיוטת מייל עם הקובץ מצורף. לחיצה על הקובץ שירד פותחת חלון מייל ב-Outlook או ב-Mail. יש גם אפשרות שיתוף ו-Gmail.
- **התראות**: במחשב, 7, 3 ו-1 ימים לפני המועד וביום עצמו. בנייד, דרך הוספת המועד ל-Google Calendar או ליומן (קובץ ‎.ics).
- **הדרך לנובל**: חזון, יעדים שנתיים, מדדי השפעה (ציטוטים ו-h-index), רצף עבודה, בנק רעיונות, מענקים, פרסים וכנסים, וטיפ שבועי.
- **ניהול**: נעילה למחשב, אישור מפורש למכשיר נוסף (באמצעות קוד מכשיר וקוד אישור), שינוי קוד, גיבוי ושחזור, הגדרות ויומן מערכת.

## חשוב לדעת
- הנתונים נשמרים בדפדפן של המחשב הזה. מומלץ לשמור **גיבוי מלא** כל שבוע או שבועיים (המערכת מזכירה).
- הנעילה פועלת ברמת הדפדפן ומונעת כניסה מקרית. היא לא מצפינה את הנתונים.
