# Baranes Lab · האתר של פרופ׳ דני ברנס

אתר אישי למעבדה, באווירה של כחול כהה מאוד, עם מסך ניהול שבו אפשר לערוך, להוסיף ולמחוק כל דבר באתר.

## מה יש באתר

- **פתיח:** רשת נוירונים עדינה שזזה ברקע (בלי תנועה למי שביקש פחות תנועה), כותרת, משפט פתיחה ושני כפתורים.
- **חלקים:** אודות (טקסט ותמונה) · מחקר (כרטיסים) · צוות (ראש המעבדה בכרטיס רחב, ושאר הצוות לפי קבוצות) · פרסומים (עם חיפוש וסינון לפי שנה) · חדשות · גלריה (עם הגדלה) · יצירת קשר (עם מפה לפי הכתובת).
- **שפה:** אנגלית או עברית, בבחירה בהגדרות (כיוון הדף מתחלף לבד).
- **בטלפון:** תפריט מקופל, וכל הכרטיסים נערמים.

## מסך הניהול: `/admin`

- כניסה בסיסמה (`ADMIN_PASSWORD`).
- **הגדרות כלליות:** שם, כותרת, משפט פתיחה, לוגו, תמונת רקע, כפתורים, צבע הדגשה, תחתית ותיאור לגוגל.
- **חלקים:** הוספה (שבעה סוגים), שינוי שם, הסתרה, הוצאה מהתפריט, שינוי סדר, שכפול ומחיקה.
- **פריטים בכל חלק:** הוספה, עריכה, שינוי סדר, שכפול ומחיקה.
- **תמונות:** העלאה מהמחשב (מוקטנות בדפדפן ונשמרות באתר), או כתובת של תמונה. בגלריה: העלאה של כמה תמונות בבת אחת.
- **פרסומים:** "ייבוא רשימה" מדביקה רשימת מאמרים, מאמר בכל שורה, והשנה והקישור (DOI) מזוהים לבד.
- **בטוח:** "תצוגה מקדימה" לפני פרסום; שינויים שלא פורסמו נשמרים בדפדפן; כל פרסום שומר את הגרסה הקודמת (30 אחרונות) עם "טעינה לעריכה"; הורדה וטעינה של כל התוכן כקובץ.

## פריסה ב-Netlify (פעם אחת)

1. ב-Netlify: **Add new site › Import an existing project** ובוחרים את המאגר `theowlwitch/sbe`.
2. **Base directory:** `sites/baraneslab` (את השאר Netlify קורא מ-`netlify.toml` שבתיקייה).
3. **Branch to deploy:** `main` (או הענף שבו האתר נמצא).
4. **Site configuration › Environment variables:** `ADMIN_PASSWORD` = סיסמת הניהול. (רשות: `SESSION_SECRET`, מחרוזת ארוכה אקראית.)
5. Deploy. האתר עולה עם התוכן ההתחלתי (`content.json`), ומהפרסום הראשון מהניהול התוכן נשמר ב-Netlify Blobs.
6. דומיין משלו: **Domain management › Add a domain**.

החלפת הסיסמה ב-Netlify מנתקת את כל מי שמחובר/ת.

## פיתוח מקומי

```bash
node tests/dev-server.mjs 8787
```

האתר ב-`http://localhost:8787`, הניהול ב-`/admin.html` (הסיסמה `dev`, התוכן בזיכרון בלבד).

```bash
npm test
```

## קבצים

- `index.html`, `assets/site.css`, `assets/site.js`: האתר.
- `admin.html`, `assets/admin.css`, `assets/admin.js`: מסך הניהול.
- `assets/common.js`: עיצוב טקסט (פסקאות, תבליטים, **מודגש**, קישורים) וקישורים בטוחים.
- `content.json`: התוכן ההתחלתי.
- `netlify/functions/api.mjs` ו-`netlify/lib/core.mjs`: השרת (`/api/content`, `/api/login`, `/api/history`, `/api/img`).
