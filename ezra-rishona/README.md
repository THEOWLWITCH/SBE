# עזרה ראשונה חינוכית · אב-טיפוס שיחה

אב-טיפוס של השיחה עם המודל (Claude Sonnet 5.5), עם פרומפט המערכת (גרסה 2.9) ומאגר הידע המלא.
אין בו הרשמה, צוותים או שמירת מידע. הוא מיועד לבדיקה: להריץ את 17 תרחישי הבדיקה, ולתת לכמה אנשי ונשות חינוך לנסות.

## מה יש בתיקייה
- `public/index.html` – המסך: שיחה, בחירת שפה (עברית, ערבית, אנגלית), שיחה חדשה, ומגירת "תרחישי בדיקה".
- `public/scenarios.json` – 17 תרחישי הבדיקה.
- `netlify/functions/chat.mjs` – הפונקציה שמדברת עם Claude. המפתח נשמר ב-Netlify ולא מגיע לדפדפן.
- `netlify/functions/kb.mjs` – הפרומפט ומאגר הידע.
- `netlify.toml` – הגדרות ל-Netlify.

## העלאה ל-Netlify (פעם אחת)
התיקייה נמצאת במאגר `THEOWLWITCH/SBE`, בענף `ezra-rishona`. היא לא נכנסת לאתר be-good.co.il ולא משנה אותו: האתר של Be Good נבנה רק מהענף main ומהתיקייה `app`.

1. **Netlify:** ‏Add new site ← Import an existing project ← GitHub ← `SBE`.
2. **בהגדרות האתר החדש:**
   - Branch to deploy: `ezra-rishona`
   - Base directory: `ezra-rishona`
   - שאר השדות נקבעים מהקובץ `netlify.toml` שבתיקייה. לוחצים Deploy.
3. **משתני סביבה:** ‏Site configuration ← Environment variables ← מוסיפים:
   - `ANTHROPIC_API_KEY` – המפתח מ-console.anthropic.com
   - `ACCESS_CODE` – קוד גישה לאב-הטיפוס (למשל 4 ספרות). בלי קוד, כל מי שיש לו את הקישור יכול להשתמש במפתח שלך.
   - (רשות) `MODEL` – להחלפת מודל. ברירת המחדל: `claude-sonnet-5-5`
4. **פריסה מחדש:** ‏Deploys ← Trigger deploy, כדי שהמשתנים ייכנסו לתוקף.
5. **שם לאתר (רשות):** ‏Site configuration ← Change site name, למשל `ezra-rishona`.

## הרצת תרחישי הבדיקה
1. לוחצים "תרחישי בדיקה". נפתחת מגירה עם 17 התרחישים.
2. לוחצים על תרחיש ← "הרצה בשיחה חדשה". הפנייה נשלחת אוטומטית.
3. ממשיכים את השיחה כמו שמשתמש/ת אמיתי/ת היה ממשיך/ה, ובודקים מול "חייב לקרות" ו"אסור שיקרה".
4. מסמנים: עבר / חלקי / נכשל, וכותבים הערה.
5. בסוף: "העתקת התוצאות", ומדביקים לי בשיחה. אתקן את הפרומפט לפי מה שנמצא.

במצב בדיקה, מתחת לכל תשובה מופיע כמה "טוקנים" היא עלתה, כולל כמה נקראו מזיכרון המטמון. ככה רואים את העלות בפועל.

## עדכון הפרומפט או המאגר
הפרומפט ומאגר הידע נמצאים בקובץ `netlify/functions/kb.mjs`. כשמשתנה משהו בפרויקט, מייצרים את הקובץ מחדש ומעלים אותו ל-GitHub. Netlify מעדכן את האתר לבד.
