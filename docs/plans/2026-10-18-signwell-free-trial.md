# ניסיון SignWell חינמי ומבודד

## מטרה

לבחון מסמך בדוי בעברית וחתימת שני צדדים בתוך דף בדיקה מקומי, באמצעות API של SignWell במצב בדיקות בלבד. הניסוי אינו מחליף את מתאם החתימה הקיים ואינו מפעיל הסכמים או שותפויות ב־BE GOOD.

## תחום הניסוי

- שימוש ביצוא DOCX הקיים כדי לבדוק עברית, אנגלית, מספרים ותאריכים.
- שירות מקומי זמני עם דף עברי, מפתח API בזיכרון בלבד ושתי זהויות בדויות.
- כל בקשה יוצרת מסמך עם `test_mode:true` וגם כותרת `X-TestMode-Enabled:true`. אין מסלול לשימוש במכסת הייצור או לחיוב.
- פתיחת תצוגת חתימה וניסיון אחזור המסמך הסופי ויומן החתימה. תוצאת בדיקה לעולם אינה מוצגת כחתימה מאומתת משפטית.
- חשבון ספק והרשמה מחייבים פעולה פרטית של בעלת המערכת. לא מכניסים אשראי, לא מקבלים תנאים בשמה ולא שומרים סיסמה או מפתח בקוד, בצ׳אט או ביומן.
- אין שינוי ייצור, מסד חי, פריסה, הזמנה אמיתית או מסמך מחקר אמיתי.

## מימוש ואימות

יחידה מקומית קטנה: כלי ניסיון מבודד, בדיקות תעבורה/חסימת ייצור ומדריך קצר. הניסוי משתמש במנוע היצוא הקיים, ללא מנוע הסכמים או מערכת הרשאות נוספים. בדיקות מול REST סינתטי מקדימות ניסיון מול הספק; הן אינן ראיה שהספק נבדק בפועל. בהרצה מול הספק בודקים `test_mode` בתשובה, תצוגת העברית, שני חותמים, מסמך PDF סופי ויומן, ומדווחים במפורש על כל שלב שלא בוצע.

## תנאים ידועים

התיעוד הרשמי אינו מציע `he` כשפת ממשק החתימה. בניסוי ייבדקו תוכן מסמך עברי והנחיות מעטפת בעברית; מסך הספק עצמו עשוי להישאר באנגלית. חתימה מוטמעת משביתה אימות דוא״ל של הספק, ולכן השלמת הניסוי אינה מוכיחה את אימות הזהות והסמכות הנדרשים לשימוש חי.
